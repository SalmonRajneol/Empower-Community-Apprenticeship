# Community Apprenticeship Dashboard

This project is a web-based dashboard designed to visualize participant performance in the Community Apprenticeship Program. Users can upload a JSON file containing participant data, and the dashboard will display key performance indicators (KPIs) and interactive charts to analyze engagement, performance, and feedback.

## Features

- **File Upload**: Upload a JSON file with participant data to generate visualizations dynamically.
- **Key Performance Indicators (KPIs)**:
  - Total Participants
  - Average Attendance %
  - Average Workshop Score
  - Average Feedback Score
  - Percentage of Participants with Mentors
- **Interactive Visualizations**:
  - **Grouped Bar Chart**: Compare average workshop scores for participants with and without mentors.
  - **Box Plot**: View the distribution of feedback scores, including quartiles and outliers.
  - **Scatter Plot**: Analyze the relationship between attendance and workshop scores, with mentor status differentiation.
  - **Line Chart**: Track average workshop and feedback scores across different age groups.
- **Responsive Design**: Built with Tailwind CSS for a clean and responsive layout.
- **Interactive Charts**: Powered by Plotly.js, offering hover tooltips, zoom, and export options.
